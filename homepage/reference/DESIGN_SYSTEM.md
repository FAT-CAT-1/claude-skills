# 里山エディトリアル — デザインシステム仕様 v1.0

日本語のホームページ（店舗・施設・士業・小規模事業者）向けの設計体系。
`assets/satoyama.css` の各数値が「なぜその値か」を記した対応表。

## 出自と扱い

2026-08-12、別の AI サービスが同じ題材で作ったサイトを自分で開いて測り、設計変数を抽出して、自分の言葉で一般化した。
**持ち出したのは骨格と寸法だけ**で、文章・画像・固有の言い回しは含まない。
書体（Zen Old Mincho / Noto Sans JP）はいずれも SIL Open Font License の Google Fonts。

⚠ **これは「型」であって「完成品」ではない。** 同じ型に別の題材を流し込めばよい、
という使い方をすると全部同じ顔のサイトになる。配色・写真・コピーで必ず差をつける。

---

## §1 設計思想（この4つを外すと別物になる）

1. **紙面に苔を置く。** 背景は純白 `#fff` を使わない。生成りの `--paper #f7f2e8` を地にする。
   白は「未完成の画面」に見え、生成り色は「刷られた紙」に見える。
2. **見出しは明朝、本文はゴシック。** 日本語で品位が要る場面では明朝が効く。
   1書体で通すと、どれだけ組んでも「管理画面」の顔から抜けられない。
3. **中央寄せの均等カードを並べない。** 版面は非対称（46:54、1.07:0.93、0.78:1.22）に割る。
   均等分割は安全だが、安全なだけで何も語らない。
4. **事実は文脈のとなりに置く。** 出典・注記を巻末にまとめず、その数字の隣に小さく置く。

## §2 配色

| トークン | 既定値（里山） | 役割 | 使用量の目安 |
|---|---|---|---|
| `--paper` | `#f7f2e8` | 地。ページの大半 | 60% |
| `--paper-deep` | `#eee7d8` | 地の段差 | 5% |
| `--cream` | `#fffdf7` | 最も明るい面（表の地） | 10% |
| `--ink` | `#20362e` | 本文。**黒を使わない**（緑に寄せた墨） | 15% |
| `--ink-muted` | `#50645b` | 補助文 | — |
| `--accent` | `#2e5b46` | 主色。ボタン・ラベル・罫 | 8% |
| `--accent-deep` | `#173a2c` | 濃色帯・フッター | 2% |
| `--accent-pale` | `#dce8dc` | ずらし色面・アイコン地 | — |
| `--clay` | `#b66d43` | **差し色。3%を超えない** | 1% |

**`--clay` の使いどころは3箇所まで。** 番号（01/02）、締めの線とドット、注記の左罫。
それ以上使うと主色が負けて、配色が「2色のサイト」に見えなくなる。

**同梱テーマ:** `theme-ai`（藍＝士業・医療・教育） / `theme-tou`（陶＝飲食・工芸・物販）。
`<body class="theme-ai">` で切り替わる。**新しい題材では必ずどれかを選ぶか、新調する。**

## §3 タイポグラフィ

| 要素 | 指定 | 1280px実描画 | 備考 |
|---|---|---|---|
| h1 | `clamp(2.8rem, 5.5vw, 5.65rem)` / lh 1.27 / ls .03em / w600 | **70px** | 明朝 |
| h1（〜680px） | `clamp(2.65rem, 13vw, 4rem)` | **42px以上** | モバイルでも縮めすぎない |
| h2 | `clamp(2.15rem, 4vw, 4.15rem)` / lh 1.42 / ls .025em / w600 | **51px** | 明朝 |
| h2（〜680px） | `2.35rem` | 38px | — |
| h3 | 19〜28px / w700 | — | 明朝 |
| ラベル | 11px / ls .15em / w700 / accent色 | — | ゴシック。`01 / WHAT WE KNOW` の形 |
| 本文 | 13〜15px / lh 1.8〜2.05 | — | ゴシック。**16pxは大きすぎる** |
| 事実表の値 | 14px / lh 1.82 | — | — |

### ⚠ 最頻の失敗: `clamp()` の上限が実描画を頭打ちにする

`clamp(27px, 6.4vw, 46px)` と書くと、1280px 幅では `6.4vw = 81.9px` が出せるのに
**46px で止まる**。上限は「これ以上大きくしない」ではなく「ここまで大きくする」値として置く。
**必ず実描画を測る**（`verify.py`）。

### 見出しは3行以内・改行を手で入れる

日本語の大見出しは自動折り返しに任せると必ず不格好になる。`<br>` で意味の切れ目に入れる。
強調は `<em>` を **1語だけ**。2語以上に付けると効果が消える。

## §4 余白とリズム

| 場所 | 値 |
|---|---|
| セクション上下 | **120px / 124px**（〜680px では 79 / 80px） |
| 濃色帯の上下 | 112px |
| 版面幅（header/hero） | `min(1360px, calc(100% - 48px))` |
| 版面幅（本文） | `min(1160px, calc(100% - 48px))` |
| 2カラムの間 | `clamp(46px, 8vw, 118px)` |
| 見出しと中身 | 62〜64px |
| 表の1行の高さ | `min-height: 88px` |

**ページ全体で明度の谷を1つ作る。** 上から `paper → paper → **accent-deep（濃緑の全幅帯）** →
paper → paper → footer(濃)`。この谷が無いと、どれだけ余白を取っても平坦に見える。

## §5 版面の型（ブロック一覧）

| # | ブロック | 割り | 要点 |
|---|---|---|---|
| 1 | `.site-header` | flex | 高さ102px。右端は塗りのCTAボタン |
| 2 | `.hero` | **46% : 54%** | 左にコピー、右に画像。背景に微かな斜線と円 |
| 3 | `.hero-strip` | `1fr 1fr 1fr 1.55fr` | 数字を3つ先出し。最後のセルは出典リンク |
| 4 | `.notice` | `54px 1.05fr 1.65fr auto` | 方針を1行で語る帯 |
| 5 | `.story-layout` | **1.07 : 0.93** | 左に画像、右に番号つき項目 |
| 6 | `.band` | **0.9 : 1.1** | 濃色全幅。右に手順1-2-3 |
| 7 | `.facts-grid` | **1.15 : 0.85** | 左に `<dl>` の事実表、右にアクセスカード |
| 8 | `.split` | **0.78 : 1.22** | 左に正方形画像、右に2枚組カード |
| 9 | `.cta` | flex | 細線＋clayのドット。左8.6%インデント |
| 10 | `.site-footer` | `1fr auto` | 濃色 |

**すべてを使う必要はない。** 最小構成は 1 / 2 / 6 / 7 / 10 の5ブロック。
ただし **2（非対称ヒーロー）と 6（濃色帯）は必ず残す**。この2つが体裁を決めている。

## §6 画像の扱い

- 画像には必ず **ずらした色面**を背後に敷く（`box-shadow: 28px 26px 0 var(--accent-pale)` または
  `::after` の矩形）。これだけで平面が立体になる。
- 実写真が無い場合は **生成する**。生成画像・イメージ画像には
  `.art-note` / `.art-caption` で **「イメージイラスト／実際の◯◯ではありません」** を必ず添える。
- 推奨点数: **hero 1点 ＋ 本文 2〜3点**。0点は不可。
- 生成の作風指定例:
  「淡い水彩と色鉛筆の風合い、生成り色の紙、彩度低め、人物の顔は描かない、
  ミニマルな日本の里山、余白多め」

**人物の顔を生成しない。** 実在の施設・店舗のイメージとして使うため、
実在しない人物の顔は誤認を招く。後ろ姿・手元・風景・静物に留める。

## §7 言葉

- **セクション見出しに機能ラベルを使わない。**
  ✗「ご利用案内」「サービス内容」「アクセス」
  ✓「申し込む前に、一度のぞいてみてください。」「毎朝、焼きたてを店先に並べています。」（どちらも架空の例）
  機能ラベルは `.label`（`03 / FACTS & ACCESS`）側へ逃がす。
- ラベルは **`番号 / 英字`** の形で通す（`01 / WHAT WE KNOW`）。連番が読み手の現在地になる。
- h1 は「誰に何を約束するか」を1文で。説明文をここに置かない。説明は `.hero-lead`。

---

## §8 アクセシビリティ（省略不可）

- `.skip-link` を先頭に置く。
- `:focus-visible` の輪郭を消さない。
- 濃色帯の文字は `rgba(247,242,232,.78)` 以上（それ以下はコントラスト不足）。
- `prefers-reduced-motion: reduce` で `.reveal` を無効化（CSS に同梱済み）。
- 画像の `alt` を空にしない。装飾画像だけ `alt=""`。

---

## §9 この体系を使わない方がよい場面

- **情報密度が主役のもの**（管理画面・ダッシュボード・比較表中心のLP）。明朝の大見出しが邪魔になる。
- **速報性・カジュアルさが主役のもの**（イベント告知、キャンペーン）。落ち着きすぎる。
- **既にブランドの規定があるもの**。指定の書体・色が優先。
