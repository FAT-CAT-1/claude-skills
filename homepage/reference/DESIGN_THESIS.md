# 設計思想（デザイン・テーゼ）の書き方と型

> **この文書が、このスキルで最も重要。** 実測比較の結果、デザイン品質の差を最も大きく作っていたのは
> 書体でも余白でもなく、**「書き始める前に設計思想を言語化し、否定制約つきでファイルに固定したか」**だった。
> 比較の経緯は `SKILL.md` 冒頭の「由来」を参照。

---

## §1 なぜ効くのか

書き始める前に方針が無いと、こうなる。

```
題材を理解する → 情報を並べる → 体裁を整える → 完成
```

この流れには**「どう見せるか」を決める瞬間が無い**。決めていないので、既定値が出る。
LLM の既定値は「中央寄せの白いカードを縦に並べたもの」であり、これは減点は無いが加点も無い。

さらに、方針を**会話の中でだけ**宣言しても足りない。会話は流れて消える。
**成果物ファイルの先頭に書く**と、そのファイルを読み直すたびに文脈へ戻ってくる。
長い作業ほど、この差が出る。

## §2 テーゼの構造（4要素・これで全部）

```
/**
 * Design: 「◯◯◯◯」— {視覚の主張を1文}。
 * Visual rules: {否定制約1}; {否定制約2}; {否定制約3}。
 * Information rule: {情報の置き方の規則}。
 */
```

| 要素 | 役割 | 書き方 |
|---|---|---|
| **① 名前** | 判断が割れたとき立ち返る先 | 情景が浮かぶ日本語の名詞句。「モダンで清潔感のある」のような形容詞の羅列は不可 |
| **② 主張** | 何を地にし、何を置くか | 「Aの上にBを置く、Cな版面」の形が作りやすい |
| **③ 否定制約** | **既定値の禁止**（最低2件） | 「放っておくと自分が必ずやること」を禁じる |
| **④ 情報規則** | 内容の構造が崩れるのを防ぐ | 見た目の規則だけだと中身が散る |

### ③ が要
名前と主張だけでは足りない。**既定値を名指しで禁止して初めて、既定値から離れられる。**
否定制約は「やらないこと」で書く。「上品にする」ではなく「中央寄せの均等カードを並べない」。

---

## §3 否定制約のカタログ（ここから2件以上選ぶ）

自分が放っておくと必ずやることの一覧。**該当するものを選んで、テーゼに書き込む。**

**版面**
- 中央寄せの均等カードを並べない（3カラム等分の反復をしない）
- 全セクションを同じ構造にしない
- 全幅の濃色帯を1つも置かないまま終わらせない

**色**
- 背景に純白 `#fff` を使わない
- 本文に純黒 `#000` を使わない
- 差し色を3箇所を超えて使わない

**文字**
- 見出しと本文を同じ書体にしない
- `clamp()` の上限で見出しを頭打ちにしない
- セクション見出しに機能ラベル（「ご利用案内」「サービス内容」）を使わない

**余白**
- セクション余白を100px未満にしない
- 情報量が多いことを密度の理由にしない

**素材**
- 画像0点で完成としない
- 生成画像に出所の注記を付けずに出さない
- 人物の顔を生成しない

**内容**
- 確認できない声・実績・数値を書かない
- 出典を巻末にまとめて追い出さない

## §4 使える型（6種・そのまま使ってよい）

題材に合うものを選び、**名前と否定制約だけ題材に合わせて書き換える**。
どれも合わないときは §2 の構造に沿って新調する。

### 1. 里山エディトリアル（同梱CSSの既定・`satoyama.css`）
```
Design: 「田舎の小さな学び場」— 生成り色の紙に、落ち着いた緑を少しだけ差す。左右をそろえない、雑誌のような組み方。
Visual rules: 中央寄せの均等カードを並べない; 背景に純白を使わない; 見出しと本文の書体を分ける。
Information rule: 出典つきの事実は、その文脈のとなりに置く。
```
向き: 福祉・教育・農園・地域の店・工芸。落ち着きと誠実さが要るもの。

### 2. 白磁（`theme-ai` 相当）
```
Design: 「白磁の帳面」— 冷たい紙に藍の細線を引く、余白の多い記録の版面。
Visual rules: 装飾の面を使わない（線と余白だけで区切る）; 差し色は藍1色に限る; 角丸を使わない。
Information rule: 数値と根拠を必ず同じ行に並べる。
```
向き: 士業・医療・研究・BtoB。信頼と正確さが要るもの。

### 3. 土間（`theme-tou` 相当）
```
Design: 「土間の台所」— 温かい生成りに素焼きの赤茶を落とす、手仕事の版面。
Visual rules: 整列しすぎない（意図的に軸をずらす）; 写真を切り抜かず矩形のまま置く; 明朝を本文に使わない。
Information rule: 値段と分量は、商品名の直後に置く。
```
向き: 飲食・パン・工芸・物販。手ざわりが要るもの。

### 4. 夜間飛行
```
Design: 「夜間飛行」— 深い紺の地に一点だけ灯りを置く、暗い版面。
Visual rules: 明るい面を画面の3割を超えて使わない; 影を使わず発光で階層を作る; 彩度の高い色を2色以上使わない。
Information rule: 最も重要な数値を、必ず最初の画面に置く。
```
向き: 技術・音楽・ナイトカルチャー・プロダクト。⚠可読性の検査を厳しめに。

### 5. 余白の間（ま）
```
Design: 「余白の間」— ほとんど何も置かない、間で語る版面。
Visual rules: 1画面に要素を3つより多く置かない; 罫線を引かない; 画像を全幅で使わない。
Information rule: 詳細は畳んで、開いた人にだけ見せる。
```
向き: ギャラリー・旅館・高価格帯。⚠情報量が多い題材には使えない。

### 6. 大判（おおばん）
```
Design: 「大判の見出し」— 巨大な文字そのものを図版として使う、雑誌の版面。
Visual rules: 見出しを画面幅の6割未満にしない; 写真の上に文字を重ねない; 中間の級数を使わない（大か小か）。
Information rule: 見出しだけを拾って読めるようにする。
```
向き: イベント・キャンペーン・作品集。⚠長文の説明が要るものには不向き。

## §4.5 型を選んだあと必ずやること

**選んだ型のまま出さない。** 型は出発点であって完成品ではない。最低1つ、題材固有のものを足す。

- 配色トークンのどれか1つを題材に合わせて振り直す
- 否定制約を1件、題材固有のものに差し替える（例: 子ども向けなので「顔の写る素材を使わない」）
- 画像の作風指定を題材の土地・季節・道具に寄せる

---

## §5 書いたテーゼの置き場所（必須）

| 置き場所 | 何を書くか |
|---|---|
| **CSS の1行目** | テーゼ4要素（§2の形） |
| **HTML の先頭コメント** | テーゼ4要素＋制作日＋要確認事項 |
| `DESIGN_NOTE.md` | 手順・期待される成果物・検証基準・却下した案 |

`verify.py` は **HTML先頭コメントに `Design:` と否定制約2件以上があるかを機械検査する**。
無ければ FAIL になり、出荷できない。

## §6 やってはいけないテーゼの書き方

| ✗ | なぜ駄目か |
|---|---|
| 「モダンで洗練された、清潔感のあるデザイン」 | 形容詞の羅列。何も禁止していないので既定値が出る |
| 「ユーザーに寄り添う優しいデザイン」 | 判断の分かれ目で何も決められない |
| 「Appleのような」 | 借り物。題材と結びついていない |
| 否定制約が0〜1件 | **既定値から離れられない。最低2件。** |
| テーゼを会話にだけ書く | 流れて消える。ファイルに書く |
